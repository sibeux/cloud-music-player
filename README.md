# Cloud Music Player - Backend API

RESTful API backend for the Cloud Music Player streaming platform.

## Running the Local Development Server

Run the following command from the project root directory:

```bash
composer serve
```

*or directly via PHP:*

```bash
php -S localhost:8000 router.php
```

Once running:
* **Interactive API Docs (Scalar UI):** [http://localhost:8000/api/docs](http://localhost:8000/api/docs)
* **Health Check Endpoint:** [http://localhost:8000/api/health](http://localhost:8000/api/health)

For an in-depth walkthrough on how PHP's built-in server works, router script details, and mobile testing on LAN, check out the **[Local Development Guide](file:///c:/Users/Nasrul%20Wahabi/Documents/00--programming/Web%20Development/cloud-music-player/docs/local-development.md)**.
